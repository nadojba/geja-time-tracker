Princípio do Geja Time Tracker
REDMINE TIME TRACKER EXTENSION CHROME

What is Geja Time Tracker?

Geja Time Tracker is a Chrome extension for Redmine users who need a practical way to track working hours on issues and review time before logging it.

Connect your Redmine

Enter your Redmine server URL and API Key, authorize only that domain, and test the authenticated user before using the timer.

Keep sessions independent

Every new start begins at 00:00:00. Pause and resume the same session, or stop it to create a pending session for later review.

Log time with control

Choose the project, issue, activity, date and description before sending a time entry to Redmine. A failed or unknown submission remains available for reconciliation.

SETUP

How to connect your Redmine API Key

The extension keeps the API Key in its local extension storage and sends authenticated Redmine requests through its service worker.

  1. Open the extension settings.Enter the HTTPS URL of your Redmine instance.
  2. Paste your Redmine API Key.The key is used only to authenticate requests to the configured Redmine domain.
  3. Test the connection.Geja verifies the current authenticated user before loading issues and projects.
TIME LOGGING

Time tracking and pending sessions

Stopped sessions are not silently submitted. They remain separate from confirmed Redmine entries until you review and register them.

No accidental mergingStarting the same issue again creates a new timer session from zero. Each pending session keeps its own duration, activity, date and description.
QUESTIONS

Frequently Asked Questions

Clear answers about this Redmine issue time tracker extension.

Does Geja Time Tracker work with every Redmine server?

It is designed for Redmine instances with REST API access enabled. You configure the server URL and API Key yourself, and the extension requests permission only for that domain.

Does starting a timer submit time automatically?

No. Stopping a timer saves a pending local session. You review the activity, duration, date and description before registering it in Redmine.

Can I use the extension on more than one Redmine account?

Sessions are associated with the configured Redmine server and authenticated user. Previous local history is preserved, while submissions are restricted to the active account.

Is Geja Time Tracker an official Redmine product?

No. Geja Time Tracker is an independent Chrome extension and is not an official Redmine product.

Privacy by default

Your time is yours.

The extension talks directly to your configured Redmine instance. There is no custom backend or intermediary service receiving your API Key. Optional metrics stay in your browser.
