Princípio do Geja Time Tracker
Privacidade por padrão

Seu tempo é seu.

A extensão conversa diretamente com a instância Redmine configurada. Não existe backend próprio, telemetria ou serviço intermediário recebendo sua API Key.

Leia a política técnica →
⌁Credenciais locaisA API Key fica somente no armazenamento protegido da extensão.
◎Chamadas centralizadasO service worker é o único contexto que faz requests autenticados.
✓Permissão sob demandaO acesso é solicitado somente para o domínio Redmine escolhido.
